Personal application

dot-drive-sync

dot-drive-sync is a personal Google Drive synchronization configuration operated by the account owner. It uses rclone to synchronize a selected Google Drive folder with the owner's computer.

What it does

The application reads file contents and metadata and creates, updates, moves, or deletes files as needed to synchronize changes in both directions. It is configured for a folder selected by the account owner.

Google's authorization screen requests Drive read and write access. The configured folder limits normal synchronization operations; it does not limit the permissions granted by Google OAuth.

Who uses it

This deployment is for the owner's personal use. It is not a hosted service for the public, is not a Google product, and does not provide a sign-up flow.

Your data

Google Drive data is transferred between Google and the owner's computer. OAuth tokens are stored on that computer so scheduled synchronization can continue. This informational website does not receive OAuth tokens or synchronized files.

Read the privacy policy for details about access, local storage, backups, and revoking authorization.
