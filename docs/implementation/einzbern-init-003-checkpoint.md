## 更新前存档核对

将更新前存档的 84 个路径逐一与 v5.8.0 正式版和 `main`（`eaf4a1af`）比对。两条基线在这些路径上的内容一致。存档中 26 项与新版逐字节相同，5 项的改动已被新版包含，53 项有差异。以下三块值得在恢复实施时按功能移植，兼容性待实测。

1. **Codex 非协调轮询（012）**。旧档已有默认关闭的设备开关和宿主拦截。按现行工单补齐默认开启的双对话主开关，并在双对话启用时显示轮询设置。在新旧设备上通过正常入口核对运行模式、实际轮询主体和页面显示。
2. **Codex 批次预检、准备和自动回交**。本机命令目录核验确认 `execution-codex-batch-preflight`、`execution-codex-batch-prepare`、`execution-codex-batch-arm` 和 `execution-codex-batch-observe` 在 5.7.1 可用，5.8.0 缺失。将静态预检、实时准备、峰值槽位选择和批终回交接入新版 Pack 派工。复验同一协调对话的 Full Access 检查、延迟或不明回执的核对，以及重复事件下的防重投。
3. **相同输入的验证证据复用**。旧档有对应实现，5.8.0 的 `gates-config-set` 缺 `--reuse`，`gates-run` 缺 `--checks-from`。单独迁移按实际命令、输入、工具和必要输出校验通过结果的能力。合并者和独立验收者核实断言覆盖与原始输出，仅补测缺失或已失效的检查。发布门仍用本次候选实跑。

移植以新版为基线，沿用现行 Pack 绑定、协调者 Full Access 核验和验收收尾逻辑。
